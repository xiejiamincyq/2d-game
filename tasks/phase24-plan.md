# Phase 24：可见的近战包围与粉红小怪提速

## 诊断

Phase 23 的测试只检查已均匀分布敌人的单帧方向，没有覆盖同一传送门出生的一团敌人。现实现的环绕在 320px 内才逐渐生效，额外间隔只有 10px，因此敌群在主要接近路程中仍像一团直线移动，视觉差异不足。

## Task 24.1：传送门敌群轨迹回归

- 用 8 个真实 SCRAPPER 模拟传送门冲量结束后的聚集队形。
- 连续运行 1.2 秒，而不是只检查一帧速度。
- 验收时敌群相对玩家形成至少 0.9 rad 的角度扇面，最近个体间距至少 44px。

## Task 24.2：强化分离与包围

- 从半屏出生距离附近就开始按稳定槽位向两侧展开。
- 提高局部分离的作用距离与权重，使额外间隔肉眼可辨。
- 保持近战敌人仍能向内接近并进入既有攻击距离；出生冲量、远程敌人、Boss 和隐身运动不变。

## Task 24.3：粉红 DASHER 速度

- DASHER 基础速度固定为玩家初始速度的 110%（`258.5 px/s`）。
- SCRAPPER 仍为玩家初始速度的 90%，远程敌人仍为 60%。
