# Phase 22：暂停重开、无人机转向与入场控制锁

## 概览

本阶段补齐暂停菜单的重新开始入口，将无人机最大转向速度从 `300°/s` 调整为 `150°/s`，并让玩家入场动画自身保证无法移动或冲刺。预计实现与自动化验证 1—2 小时，之后进入人工试玩。

## 实现顺序

### Task 22.1：暂停菜单重新开始

验收标准：

- 暂停菜单显示“重新开始”按钮，并复用现有清档、解除暂停和重载场景流程。
- 按钮至少 44px 高，支持键盘/手柄焦点，暂停菜单默认仍聚焦“继续”。
- 960×540 至 2560×1080 的既有布局门槛继续通过。

### Task 22.2：无人机转向再平衡

验收标准：

- 无人机激光最大转向速度固定为 `150°/s`。
- 现有射线命中、锁定、遮挡和持续点燃机制保持不变。

### Task 22.3：入场控制锁

验收标准：

- `begin_entrance()` 激活后，即使外层错误地启用了物理处理，移动与冲刺输入也不能改变玩家物理位置。
- 入场结束后的既有首波准备、输入松开门禁和正常移动不受影响。

## 验证

- 先运行 UI、无人机和移动专项测试，确认修复前失败、修复后通过。
- 运行完整测试、性能门槛、Windows PCK 导出与 120 帧主场景冒烟。
- 审查差异后创建聚焦提交并推送，发送完成邮件并直接启动当前工作树游戏。
