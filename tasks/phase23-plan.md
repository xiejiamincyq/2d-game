# Phase 23：无人机点燃优先级与近战鱼群运动

## 目标

让无人机把点燃视为一次“处理完成”：存在未点燃目标时立即把锁定转移过去，而不是继续盯住已点燃目标。近战敌人从单纯直线追踪改为追击、局部分离和环绕占位的组合运动，减少扎堆并形成包围趋势。同时删除过载状态本身对所有伤害来源的直接倍率，收回过高爆发。

预计实现、自动化验证与发布检查耗时约 1–2 小时，完成后进入人工试玩。

## Task 23.1：无人机点燃优先级

验收标准：

- 在未分配候选中，任何未点燃敌人的优先级都高于已点燃敌人，距离只在同一燃烧状态内排序。
- 当前目标被点燃后，下一次选定应切换到可用的未点燃敌人。
- 多无人机仍优先分散索敌；全部目标均已分配或点燃时保留最近目标回退，Boss 单体战不丢失火力。

验证：扩展无人机目标选择回归测试，先确认旧逻辑失败，再实现并通过 Phase 20/21 与性能测试。

## Task 23.2：近战敌人鱼群运动

验收标准：

- SCRAPPER、DASHER、BRUISER 在追击玩家时对近距离同伴产生分离力，重叠或过近时主动拉开小间隔。
- 每个近战敌人使用稳定但分散的玩家周边占位方向，在接近玩家时逐渐由直追转为包围，不影响攻击距离判定。
- 远程敌人、Boss、出生冲量、隐身扩散与现有移动速度规则保持不变。

验证：扩展 EnemyBehaviorTest，以真实 Enemy 节点验证相邻个体相互分离、多个个体产生非同向的环绕分量；运行性能与全量测试。

## Task 23.3：删除过载直接伤害加成

验收标准：

- 过载不再改变子弹、地刺、无人机激光、电弧、冲刺及燃烧等任何伤害倍率。
- 过载的射速/弹道数量、地刺尺寸与持续时间、激光宽度、电弧范围与频率、移速、冲刺冷却和免伤等非伤害效果保持不变。
- 流派等级、卡片和终极进化提供的常驻伤害成长不受影响。

验证：更新 DamageTest 与 Phase20Test 的过载数值契约，先确认旧倍率导致失败，再删除过载伤害修饰器并通过相关测试。
