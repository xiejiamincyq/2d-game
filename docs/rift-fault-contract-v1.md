# R2 裂隙机关：实现前契约

2026-10-11，第六R1已实际通过285 Godot/290168断言、36 Python/272测试及独立包/release终态，84源未变，见[完成审查](art/rift-map-review-v1.md)。本文件是R2实现前决策，不代表机关已做；开始实际R2资源不存在RED，R1完成快照不再随R2重写。数值来自[第六规格](rift-sixth-chapter-spec-v1.md)，候选必须用正常玩家真实物理验证后才接受。

## 可见动作与有限时钟

固定小台座负责提示，危险圆沿台座左右各80px的固定短轨迹运行；默认水平、可用种子反向，不追踪玩家，也不拖着地形或推挤身体。候选半径20、提示0.4秒、活动0.35秒、冷却4.2秒、每轮最多尝试一次18伤害。提示为低强度短虚线及台座小标，活动仅20px实色裂痕与细短尾，不新增全屏/长时间地面警示。

RiftFault是一个Node2D时钟，不做敌人/奖励目标，不由AnimationPlayer/METHOD轨道造成伤害。状态只为INACTIVE、COOLDOWN、WARNING、ACTIVE，活动圆的唯一进度同时决定实际像素中心与判定中心。每步至多一次状态切换，跨状态不携带长帧超额时间；单次大于正常物理范围的活动步不能瞬间扫完整160px并造假命中，进入安全冷却并重新提示，不补发被省略的活动。

实现前细化：活动单步上限候选1/15秒（允许正常30/60/120Hz，不支持长帧瞬扫）。到达活动终点的那一帧仍保留ACTIVE/终点圆可见，下一帧才冷却，避免端点命中发生时像素已消失；没有额外重复命中。暂停/入场/隐身恢复用各台initial_delay重新错开，不能四台统一4.2秒后同时发作。damage回调中显式禁止重入enable，关闭仍允许，防止“关闭→开启”重新武装同一活动。

## 地形、命中与取消

预留点只是候选，不把导航clear当物理clear。启动前检查完整路径的有限胶囊形状、世界边界/出生/Boss缓冲、真正物理地形；移动角色共享layer1不能误当墙，查询饱和一律拒绝启动。必要时使用有上限的动态RID排除，不为通过测试放开碰撞mask。不安全的轨迹整轮拒绝，后续修改若支持截短则必须单独测试，不能跨墙后继续伤害。

活动中用危险圆上一中心→新中心与玩家上一位置→当前位置的相对扫掠圆判定，而不是只看帧末或将整条160px线始终当伤害区；站立和正常位移对照都要证明这一点。标记attempted必须早于take_damage及死亡/重入回调；包括免疫拒绝，也不重复尝试。暂停、入场、玩家隐身时清活动进度和上次位置，恢复从新的完整提示/冷却开始，不扫过暂停期间位置差。目标或地图Owner死亡/离树、bind重换、显式关闭、缩放/旋转/非有限坐标非法时彻底取消并清连接，不残留活跃像素。

## 地图接口及验证顺序

RiftFault提供configure(layout,player,site,direction,initial_delay)、bind_player、set_enabled、advance、get_current_center/get_fault_path端点只读查询。坐标为layout-local，平移支持；旋转/缩放不偷偷转换物理半径。配置/关闭幂等，重配先清Owner/Health/退出信号。公开返回轨迹不允许调用方改权威几何。首次加载发现get_path与Node原生方法冲突，失败日志保留于rift-fault-unit-green-v1.log；改名get_fault_path并加原生NodePath回归，不把解析失败记作绿色。

RiftField归地图所有：configure(layout,seed,player=null)、bind_player、set_active(enabled,count=2)、clear；默认四台休眠，真实COMBAT才启普通两台/风险四台，种子顺序且至少0.37秒错开。清场、奖励、失败、Boss战停用；敌人Director只负责授权，不复制时钟。Main和永久进度不增加机关特例。

先RiftFaultTest缺资源语义RED，然后有限状态/静止伤害/重复和重入/生命周期绿色；RiftFaultPhysicsTest用实际235px/s、16.9px玩家，30/60/120Hz、0.15秒反应，横向/纵向/斜向正常方向输入，实际扫掠/薄墙/动态敌人不阻断/场景平移/安全区对照。最后才RiftFieldTest与实际地图GPU，至少捕获提示与移动活动圆在同画面内、与玩家身体/设备轮廓一起查看；不能用屏外时钟状态代替真实危险像素。

准备过程历史：R1全量运行中先在ignored build内写规范单元夹具草稿`RiftFaultTest-draft-v1.gd`，当时未运行、不计RED/GREEN，84运行源保持不变。R1实际终态通过后已移入规范tests并真正跑“资源不存在”RED，之后才写机关生产实现。夹具中的受控目标位置采样用于几何/生命周期，不冒称正常Player移动或躲避。

当前专项实际终态：RiftFaultTest36、RiftFaultPhysicsTest1866（882真实移动，18种Hz/方向，站立18/薄墙/动态/饱和）、RiftFieldTest496（12种子/2或4/恢复交错/重配死亡/重绑定）、RiftFieldPhysicsTest5348（2653真实移动、30/60/120Hz双绕路）均退出0。原生GPU202检查/13PNG/42实际位移/30源不变，十三图已实际查看；短警示和活动裂痕同帧可见并正确取消。当前全量/独立PCK尚未终态，不勾R2，不发R2完成邮件、不开放第六入口；详细证据见后续机关审查。

任何躲避失败先保留RED并调整机关时序/路径，不改玩家速度、半径、无敌或血量。阶段总门仍是当前全量、独立包及资源/保存冻结；只是机关通过，不解锁第六入口或标第六/整个goal完成。
