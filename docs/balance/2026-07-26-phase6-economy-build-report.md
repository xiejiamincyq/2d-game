# Phase 6.1 经济与三流派构筑平衡报告

## 结论

正式波表与价格曲线能够形成持续购买选择。三次试玩反馈后，本阶段进一步重做三路线卡牌数值：火力明确多线/单发取舍，机动把强度从冲刺转移给地刺半径与触发频率，工程显著强化电弧伤害与蓄能速度。金币改为全图自动追踪后，经济样本仍沿用保守的 `85%` 入账率，避免把必达拾取错误当成额外购买力。

调参后，三条路线均满足以下目标：

- 前两次结算形成可辨认的路线，辨识率不低于 `90%`；
- 每阶段付费购买中位数为 `[1, 1, 2, 2, 2]`；
- 存钱后双购机会率为 `44.7%–53.1%`；
- 完全买不起率和买空剩余五张率均为 `0%`；
- 聚焦路线在第五次结算获得终极进化，达成率 `100%`；
- 三路线终局持续输出代理最大/最小比从 `1.69` 收紧到 `1.29`；
- 各聚焦路线核心机制贡献占比分别为火力 `95.0%`、地刺 `63.1%`、电弧 `24.9%`；
- Boss TTK 代理中位数为 `18.0–23.1s`，三路线均满足聚焦构筑 `15–45s` 门槛。

## 样本与假设

- 样本量：三条路线各 `64` 局，共 `192` 局、`960` 次结算。
- 随机性：每局使用固定且可复现的种子，报价来自正式 `UpgradeSystem`。
- 收入：直接读取正式六阶段波表和敌人金币；普通阶段按 `85%` 拾取效率入账。
- 选择策略：免费奖励优先本路线进化/核心卡；付费优先本路线核心卡、其次本路线支援卡，之后才考虑跨路线卡，并持续购买所有当前可负担项目。
- 输出代理直接读取升级后的正式 `Player` 属性和流派伤害倍率。
- Boss 单体命中假设：中心枪线稳定命中，每条侧枪线按 `50%` 命中；轨道风暴每次环射按一发命中；移动 Boss 穿越地刺走廊按 `0.45s` 暴露时间计算，并把扩大的地刺半径最多折算为 `15%` 命中可靠性增益。

这些代理值用于自动回归和路线间相对比较，不替代人工走位、命中率与生存压力试玩。

## 机制调整摘要

| 路线 | 调整 |
| --- | --- |
| 火力 | 基础伤害卡提高，射速卡略降；多枪线伤害惩罚加深，攻城弹头改为更明确的伤害/射速交换。 |
| 机动 | 地刺基础伤害提高并新增独立半径/触发间隔；地脉共振强化三项地刺属性；裂地超载降低冲刺爆发、保留铺路核心。 |
| 工程 | 电弧基础伤害 `18→34`、基础蓄能 `2.4s→1.85s`；电容与继电器分别强化伤害/覆盖和脉冲频率。 |
| 通用 | 删除两张拾取范围卡；旧存档中的卡牌 ID 会自动迁移为地脉共振和电弧继电器。 |

## 自动门禁

`EconomyBuildTest` 会阻止以下回归：

- 正式波表金币收入未经复核发生变化；
- 中位购买数偏离每阶段一至两张，或三路线购买力重新分化；
- 双购机会过少、完全买不起过多或稳定买空商店；
- 第二次结算仍无法辨认路线，或第五次结算无法获得进化；
- 三路线输出代理差超过 `1.35×`，或聚焦构筑 Boss TTK 越出 `15–45s`。
