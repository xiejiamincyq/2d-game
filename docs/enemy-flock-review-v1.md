# 小怪群体移动与大型碰撞盒绕行

用户实试玩反馈驱动的玩法修复；`5分钟超载`分支。不属于新美术风格或公开发布。榴弹另见[速度修复](grenade-velocity-review-v1.md)。

## 实现

五种小体型敌人保留自身追击/包围或射程目标，叠加局部速度对齐、低权重聚合、近距分离；附近小怪的方向与速度都影响它。群体配速只影响自身上限的20%，不能复制快怪速度突破自身上限。大怪不参与对齐/配速，避免整个群体被拖慢。

提前预测前方慢大怪的碰撞走廊，选择并暂时保持一个绕行侧，不等撞上才排队。碰撞半径、实体碰撞层、生命/伤害、各类型基础速度均不改；最后仍使用真实`move_and_slide()`，地形回避在群体转向之后保留。

平滑限制作用于群体目标的转向与配速；地形回避、远程射程约束与减速上限优先，不声称所有最终转向都严格平滑。近战攻击停步、出生冲量与隐身分散沿原早退流程。远程处于相机安全区时，群体不能逆转其过近撤退/过远靠近意图；相机边缘的返回优先级继续高于撤退，在最终转向后复用原安全区约束。

WaveDirector通过256px网格查询240px邻域，每物理帧首查询及成员变更时重建一次索引，而非每怪遍历全场。额外一格覆盖同帧普通/出生运动，最终按活体当前位置精确筛选；出生、退出、恢复波次显式失效。大幅同帧传送若未来加入，必须失效索引。密集聚集在同一邻域时仍需处理所有近邻，不声称任何分布下线性复杂度或已验证最低硬件FPS。

## 红测与实测

原始日志保留在ignored `build/diagnostics/gameplay-feedback-v1`，失败未覆盖。

- 独立原始`flock-red-v3.log`：33断言中6项行为失败，非接触邻居的上下运动与速度变化均无效；真实地图中，大怪静止/20px/s移动堵路，5秒分别275/272帧接触，小怪未超车。先前测试装配失败v1/v2不是有效行为红测。
- `flock-grid-green-v1/EnemyFlockTest`：33断言通过。静止与20px/s大怪两场景均在5秒内绕过；0接触帧、0地形穿透，最小表面间距分别41.28/44.75px。0.15秒已侧移26.46px。只证明这些固定真实碰撞场景，不保证所有随机地图/任意密集组合永不堵塞。
- 固定非接触邻居，上下运动导致小怪速度分别`(194.50,-58.60)`与`(194.50,58.60)`；慢/快邻居对应175.2/209.2px/s。不是只改随机朝向，也不是只改距离分离。
- `flock-policy-red-v1`曾捕获远程被推向过近玩家的退化，`flock-policy-green-v1`修复后8断言通过，覆盖死亡/排队释放/已释放/远处邻居、射程意图、转向步进、速度上限、燃烧减速和攻击停步。
- 独立审查另捕获群体覆盖远程相机返回策略。`flock-camera-red-v1`真实固定Camera2D及CombatView.Reference，在3远程类型×4边界×区外2px/区内1px共24情形均重现逆向。最终转向重用相机约束后，`flock-camera-green-v1`的Policy80、Behavior2270、Flock33断言均实际退出0、无错误；代码复审Approve，Critical0/Required0。
- `neighbor-grid-red-v1`捕获全场数组查询；首次网格绿测捕获已释放引用在函数入口的类型检查错误，保留失败日志。`neighbor-grid-green-v2`10断言通过，513体分散场景候选扫描少于30；覆盖同帧配额内移动、出生、释放、下帧刷新和清空，不把候选计数当帧率。
- 相机补丁前`full-gate-v1`：78 Godot套件173720断言、35 Python套件269测试，实际退出0。临时引擎日志一同保留。子进程APPDATA隔离；20项原有用户脏文件hash不变。最终完整门另记录，不继承这次计数作为最终源验证。
