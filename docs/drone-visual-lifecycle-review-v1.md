## 真实故障与最小修复

原生 Vulkan 自然六波录制 `natural-render-08-v1` 虽进入胜利并生成180张六景原帧，原始日志却有3221条 SCRIPT ERROR，全部来自已释放激光的访问。因此外部检查拒绝，不能将退出0或工具自身的 valid=true 当成通过。

根因不是渲染透明度：Main把projectiles容器中的所有Node2D都当成临时子弹，按节点原点越界删除。玩家合法中心距边界16.9px，无人机轨道半径48px；其持久LaserBeam原点可以自然越界，但Player仍持有该节点。锁定标记也同属由Player持有的视觉，不应由通用弹道边界回收。

Main只排除持久LaserBeam和DroneLockReticle；普通Projectile与非持久LaserBeam仍按原规则越界删除。Player的无人机计数、目标选择、伤害、位置、计时、数组创建/缩减与自身清理不改。没有用每帧重建节点掩盖持续误删，也未移动节点父级或扩大地图。
