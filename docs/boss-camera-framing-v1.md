# Boss战取景修复 v1（2026-10-04）

保持既定纯2D Q版薄荷农场与明显轮廓，取消所有网页端交互，由工作区判断。本文是取景技术切片，**不是S3或整个项目完成、人工试玩签收、最低硬件/发布批准**。

## 实现与空间合同

[ADR-001](decisions/001-boss-camera-framing.md)规定独立Boss取景与统一导航参考。Boss入口完成后，相机根据真实可见HUD grid、Boss血条、超载、连击、toast、收集六面板的viewport外框，保守取中间可用带；额外保留16px外边距及16px受击偏移余量。双方保守身体外框可容纳时平移/必要缩放，zoom限定0.80—1.00；不可容纳或平滑过渡尚未完成时优先保住玩家，并显示奶油底/深青边/珊瑚箭头的BOSS边缘方向标记。

玩家用54px视觉半径包住84px绘制区域及附着武器，不扩大碰撞。Boss使用实际Sprite完整纹理外框，包含透明边缘，不是逐像素掩码。CameraEffects继续拥有offset/rotation；没有修改伤害、速度、攻击计时、碰撞、地图物理边界或存档格式。相机只在Boss阶段放宽有限边缘取景，结束/无Boss恢复local position0、zoom1、smoothing8及原限位；暂停冻结构图并隐藏提示。

`CombatView`统一Boss、远程敌人、导演安全生成区及portal距离。Boss阶段参考视区只跟随玩家、viewport和原世界边界，保持1倍/8.0参考跟随，不读取Boss或呈现镜头。**这改变旧相机驱动导航的空间合同，不能说自然AI轨迹或玩法结果零差异。** 普通无Boss保留原实际相机读取路径。
