# 首关遭遇与风险奖励工程审查

2026-10-09；5分钟超载。M2.2b调度核心与隔离真实战斗已实现；尚未接入Main/正式关卡选择，不是首关闭环或全部骨骼完成。

## 接口与选择

独立`NurseryEncounterDirector`持有章节状态与种子：苗圃外围（14–18追击怪、2–3吐弹怪）→领取真实构筑奖励→孢子植床（20–24追击怪、4–5吐弹怪）→再次构筑→路线选择。

- 保守补给：实际增加12金币、恢复最多20生命，随后首领准备。
- 高风险根巢：额外30–34追击怪、6–7吐弹怪，实际清场后多一次免费构筑；完成奖励事务才增加35金币，随后首领准备。不提前发钱/跳战斗。
- 首领当前为明确标注的旧Overseer过渡演员，**不是藤冠守卫成品**，没有改它的攻击动画/制作新大型攻击。正式新首领仍依赖M3全角色骨骼门及M4。

`start_run(seed, Player, enemies, projectiles, portals, UpgradeSystem, ArenaLayout)`必须传入真实类型与同一玩家的构筑实例；启动一次。`encounter_prepared`后`begin_encounter`启动战斗；真正清空出生队列、门户和活敌人后进入3秒收集窗。`reward_ready`提供原构筑系统事务，`claim_reward`/`purchase_reward`委托其唯一发奖策略；`finish_reward`验证遭遇序号、事务、已领取与完成状态，再推进。两次普通奖励后`route_ready`，只能接受一次`supply`或`risk`；`chapter_boss_ready`后`begin_boss`才生成实际首领。`chapter_cleared(1)`不写永久存档，未来由正式协调器核对状态/实例并保存；不能只凭UI或信号名解锁。

章节使用独立随机数生成器构造敌群与顺序，不复用原六波列表；地图种子沿用新苗圃profile。`get_encounter`深复制，旧pending_stage和旧稳定快照入口明确拒绝。本步没有打开未制作的关卡、写入用户存档或迁移旧局内快照。

## 架构选择与自审

选择在章专属子类中复用现有WaveDirector的实际敌人/门户生成、碰撞安全、鱼群邻域与伤害/掉落链，而不复制约数百行通用战斗设施，也不向Main增加大量条件。章节调度/奖励和所有公开旧波次推进方法分离；继承的六波准备/启动/结算/最终胜利/旧快照方法全部拒绝。只使用公共演员设施所需的一项rate与局内难度槽，不把wave_index当chapter或永久进度。

代价：暂时依赖基类的出生/门户字段与回调。后续章节消费者必须使用上述chapter接口，不能用旧Main波次回调直接驱动它；当多个章节真正需要共同变化时再提取战斗生成器，当前不创建预测性的通用事件总线。原Main/WaveDirector与旧试玩保持未改。

正确性必修项均有RED→GREEN：未授权跳阶段、过期奖励、重复发奖、删除活怪/活Boss、实际玩家死亡、伪造活Boss死亡、无关节点退出。发现同步金币通知可重入路线并重复发奖后，用`RESOLVING_ROUTE`在发奖前锁定，再做真实通知回调复现验证。首领只接受当前实例的实际零血/死亡标志与退出，外来退出不能破坏在战首领。

测试最初误用了自动命名碰撞子节点路径及入场保护期伤害；改成真实圆形形状/半径检查，并等待原首领的自然入场时钟，不修改入场/伤害保护。独立专项最终363断言通过，日志`nursery-encounter-green-v4.log`。这是真实Node/Health/Upgrade/portal集成，但用测试伤害清场和推进门户时钟，**不称为普通输入通关或真人手感验证**。

## 普通输入与原生画面证据

`VerifyNurseryEncounterRun`在实际新地图中组装原Player、真实Enemy/Upgrade/新Director；所有玩家运动、瞄准、射击均来自普通输入，使用已有随机探索/遇阻脱困pilot。没有改血量/速度/伤害、无敌、穿墙、直接姿态或手动假造敌群。脚本不会访问用户存档。身体、吐弹怪和弹丸仍有过渡旧资源，不提升为全新动画验收。

v1/v2隔离GPU短测被保守矩形导航边界误判为穿透，没有批准。v2异常位置记录表明实际圆形碰撞距矩形仍有0.07–0.63px间隙；单独红测区分可走圆角与真实侵入，再以圆形距矩形最近点验收，并保留0.05px浮点接触容差、世界边界与实际侵入拒绝。**没有放宽生产寻路/碰撞**。空Array跨动态脚本调用时类型不匹配也被严格入口拒绝；改为显式Array[Dictionary]，专项10断言通过，失败日志保留。

实际OpenGL GPU v3：640检查、20帧、547次相邻玩家位移、121个真实弹丸、9次击杀、7次随机探索方向更新，短测末次采样HP100且仍在第一遭遇COMBAT。选定源hash/帧hash和时间记录于`docs/art/previews/campaign/nursery-encounter-input-v3.json`，预览已查看。只证明隔离第一遭遇普通输入活动，不是Main入口、全部遭遇/Boss清场/保存解锁、真人试玩或密集帧率证明；未覆盖的内容不勾完成。
