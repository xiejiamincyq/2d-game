# 本机自然整局绘制回调间隔基线 v1

本片完成一次本机基线采集，不是性能优化、稳定60FPS承诺或项目整体验收。生产代码、音效与既定美术风格未改。

## 方法与运行条件

- 基线HEAD：`ddad04286835b0b9634bcf28318c1937652171b2`；run：`native-perf-2b29d2d202`。
- 原生命令（工作目录为本分支工作树）：

```text
godot_console.exe --path . --audio-driver Dummy --resolution 1280x720 --script res://build/diagnostics/local-perf-v1/NativePerformanceProbe.gd -- --run=native-perf-2b29d2d202 --seed=20260909 --steps=18000 --clock=realtime --mode=flow --movement=dash
```

- 实际进程父链：console父进程5220、原生Godot子进程40412；命令来自启动记录/运行中进程核对。引擎返回的arguments仅保留`--script`，不能单独证明全部启动参数。
- Godot4.7 stable、Forward+、Windows显示驱动、RTX5060 Laptop GPU；Engine.max_fps=0、vsync_mode=1。没有固定FPS、写电影、截图或画面回读。
- 探针继承现有`VerifyNaturalRun.gd`：真实Input随机驾驶/停滞脱困、独立存档、种子控制、60Hz物理与1280×720 SubViewport。音频关闭，Main正常战斗时钟/受击停顿保留；没有写玩家位置或更改生产控制。
- `RenderingServer.frame_post_draw`期间用单调微秒钟记录回调间隔，仅采PLAYING，状态/波次切换重置上一时间点。原始28727条、上限120000、未截断。过程/物理/draw-call监视器数值是gauge，不用于单帧耗时或GPU耗时计算。
- 硬件信息采于运行后：Ultra7 255HX、20核/20逻辑处理器、约15.36GiB内存，NVIDIA驱动32.0.15.9191；另有Intel与GameViewer虚拟显示适配器。运行后电源方案显示Performance。未控制前台焦点、后台负载、温度或供电条件，且采集器本身有计时/监视器/数组开销，未做无探针对照。

自然流程9377个战斗物理样本、六波正常胜利、603击杀、HP120；R重开与结算清档验证通过、真实六存档前后不变、实际进程退出0。相邻位置变化超过2px有8416次（包含场景边界，不能当路径总距离），驾驶累计124次随机换向、6次脱困尝试。885个物理样本保留慢动作受击停顿，未强制time_scale=1。末样本wall为171.858008秒，是从诊断started起计时，包含START/WAVE_INTRO/SETTLEMENT等非PLAYING时间，不是净战斗时长或完整Windows进程用时；冻结v1摘要字段`reported_playing_wall_seconds`命名不准确，v2摘要改为`last_physics_sample_wall_seconds`并增加纠正说明。原始采样和全部统计不变。
