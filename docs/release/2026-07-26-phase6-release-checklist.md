本机没有 Godot 4.7 官方 Windows 导出模板，因此本阶段没有伪造或下载正式独立 EXE。`scripts/tests/run_release_checks.ps1` 不依赖模板，可以持续验证资源编译与 PCK 启动；正式交付 EXE 前必须在 Godot 的 Export Template Manager 安装完全匹配的 4.7 stable 模板，再执行 `--export-release`。

- 暂停、结算、结果页能用鼠标和键盘完成关键操作。
