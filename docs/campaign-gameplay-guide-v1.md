# 当前六关玩法说明

2026-10-12，针对5分钟超载工作树源码，不是旧v13或A5冻结包。六关已接入正式入口，整体最终验收仍在进行；这里描述当前机制，不宣称真人手感、最低硬件、全部许可或公开发布通过。

## 开始、选关与永久进度

新进度从第1区开始；主按钮继续最高已解锁区，不恢复关卡中途状态。“六区档案”可重玩已解锁关卡。每次开始/重玩生成新地图种子：地形有阻挡碰撞，必须绕路，不能穿越障碍。击败真实关卡首领且保存成功后才解锁下一关。保存失败可重试，不能假称已解锁；第6关通关记录六关完成，没有第7关。

角色采用原创不透明纸偶和Godot原生二维骨骼。隐身有明确透明度变化；不是把所有角色渲染成半透明。所有存活小怪有真实血量条，大型敌人/Boss另有对应显示。攻击以头顶短感叹号和收敛的弹道/落点/边界提示表达，身体动作与危险判定仍需分别阅读。

机关不是永久铺满的伤害地毯：启用时机由遭遇状态控制。风险路线增加敌群和该区机关压力，不能把仅有地图差异当作全部关卡差异。

二关两段必经遭遇各10处热区、风险战16处，热区橙圈倒计时0.65秒；中央通道不铺热区，出生和Boss缓冲区保持。各Boss必要攻击有锁定扇区、弹道或落点边界；二关热喷口0.70秒、四关封印0.50秒、六关窄束0.50秒预警，身体要完全离开边界。无普通移动直线撤离路径或警示期间通路被堵时取消本招；不是保证不移动也不会受伤。[六关技能参数与验证边界](campaign-boss-fairness-v1.md)。

## 一局的流程与构筑

两段必经遭遇，分别清场、拾取和整备，然后选择路线。保守补给增加12金币并恢复最多20生命，直接进入首领前整备；风险路线增加一次战斗，带来额外免费构筑机会，完成后增加35金币。风险收益要先完成战斗，不是点按钮即领取。

第1关遭遇战有补给保底：第5次有效击杀前至少掉过一个20生命血包、第8次前至少掉过一个9点小护盾；此外小怪有8%血包、10%小护盾随机掉率。每场独立重置，不保证提前失败的短战斗也已掉落，更不代表自动恢复。藤冠守卫根刺以橙色圈与奶白收缩倒计时预警，中心锁点0.8秒后触发，其余点每隔0.12秒依次刺出；落点不跟随，及时离圈。没有直接可通行撤离方向时会取消该次地刺，伤害仍为60。

每次整备免费选一张卡，免费选择提升对应流派等级；金币追加购买不提升流派等级。首领前还有一次独立免费整备：流派达到3级且必需模块齐备时可选该系进化，本局最多一项。火力的榴弹协议、机动的顶级刺客、工程的雷网矩阵会改变实际攻击，但不是永久存档升级。退出/重开后局内金币、卡牌和成长重置，永久关卡解锁保留。

榴弹继承玩家位移速度的30%，基础速度使用现行参数；雷网矩阵电弧触发间隔保留加长50%的规则。全部敌人基础伤害保留此前三倍调整；各区角色还有自身血量/攻击策略，不保证所有敌人打一下伤害相同。超载是正常连杀充能机制，击杀提示当前使用[原创0.18秒合成声](audio/original-overdrive-cue-v1.md)，旧来源不明MP3不再随运行包加载。

## 操作与退出

WASD移动、鼠标瞄准、左键持续射击、右键向准星方向冲刺；空格或Esc暂停/继续。整备通过实际卡牌和完成按钮确认；首领前整备不能直接跳过免费选择。通关/失败后可重新探索新地图或返回帐篷。手动暂停会冻结正常战斗；通关仅允许已脱离碰撞的死亡视觉尾段完成，不让活敌继续攻击。

旧波次兼容模式从主界面单独进入，仍有自己的阶段存档与C/R快捷键；不要把其“继续上一局”当成六关途中保存。不要复制自动测试的隔离进度到玩家存档。

实现依据：ChapterSceneRegistry的1–6就绪名单、ChapterRunDefinitions的地图/Director/提示、各区EncounterDirector、ChapterEncounterDirector路线交易、ChapterRun保存/重玩及CampaignStartScreen真实入口。历史源绑定验收与最终当前源码验收分开登记；这份指南不改战斗数值、用户存档或旧冻结包。
