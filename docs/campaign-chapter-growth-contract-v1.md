# F3章节成长上下文与首领前整备契约

2026-10-12，实施前决定；不是运行验收。用户已授权自主常规玩法决策，整体goal active，不发布，不提交中间工作。

## 为什么不能仅修改旧门槛

真实ChapterEncounterDirector每章两次必经、可选第三次风险结算。UpgradeSystem只有免费领取增加family_levels，付费仅升卡牌rank；两次免费最多家族3级，风险三次最多4级。旧波次门要求第4波且家族5级，两条件均不可达。上一份F3计划保留“家族5级”的假设因此被当前源码证据推翻，不能为了凑5级伪造波次、无意义加等级或直接授予进化。

## 决定

旧`setup(player)`、波次第4波/家族5级、价格曲线、付费不升家族、原快照维持。增添fresh-only `setup_chapter(player, chapter)->bool`，只允许1..6和尚未开始的成长对象；真实ChapterRun使用它。上下文不能在结算/获得升级后被切换，非法初始化不开始章节。

正式关卡在供给选择后或完成风险奖励后进入一次明确“首领前整备”，仍使用已有六报价/一免费/金币购买事务。`prepare_chapter_finale(completed_encounters)->bool`只允许已完成且已关闭的第2或3遭遇结算；计数必须等于真实已有settlement_wave，不制造第4波。生成新的transaction以拒绝旧报价/重复领取，finale最多一次，完成后才允许进入Boss。

章节进化资格为：两次及以上真实结算；专注流派免费成长达家族3级；既有必需模块满足；本局未选进化。火力两次同系即可；机动需地刺，工程需无人机和电弧。在首领前整备保证放入最高等级的合法流派进化，其他普通选择仍可选，最多一个进化。缺必需模块的高等级流派不能挡住次高合法流派。没有合格流派时只给普通报价；不直接授予进化。

供给仍12金币/20治疗、两次战斗；风险仍额外遭遇/一次普通构筑与35金币，然后同样首领前整备。风险回报仍多一轮构筑和金币，并承担额外战斗，不靠降低伤害来保证通过。原基础伤害、进化伤害/射速/弹速/电弧间隔参数不在此切片改变。

输出追加`stage_kind`区分章节遭遇/首领整备与旧波次；数值wave字段仍为实际遭遇计数以保留价格/已有调用语义。章节不恢复旧波次快照，永久档仍仅保存章节解锁，不增加中途续玩/迁移。

## 分片与验收

1. Growth + ChapterRun + 独立受控ContextTest（3）：接口/资格/一次性真实交易，旧模式和Snapshot回归；受控fixture金币不作为自然战斗证明。
2. ChapterEncounterDirector + FlowTest（2）：供给与风险实际转首领前奖励、未领取不能Boss、完成只推进一次、取消/失败/原奖励正确。旧独立Director夹具若非章节上下文可保留原行为，但真正Chapter必须绑定新上下文。
3. ChapterRun/ChapterRunUI + UI测试（≤3）：标题、资格和按钮说明与机制一致；不是把第3/4波改名成遭遇；三分辨率实际GPU选择与合法交易。
4. 普通驾驶构筑 + 真实GPU（≤3）：从实际菜单入关，普通战斗获得金币/奖励、选择前置与进化，三系/多个seed/风险与重玩记录。无直接stat、金币、奖励、伤害或Boss死亡注入。再按测得结果决定数值，不先宣称平衡。
