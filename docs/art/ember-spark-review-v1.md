# 火花散射手：第二关普通敌族骨骼与短程散射

2026-10-10，分支 `5分钟超载`，M3.2 区域变种阶段。原创墨线纸偶 Q版，自主审查为 `style-approved`，不是 `gameplay-approved` 或 `final`。没有付费下载、第三方安装或直接复制参考作品。

## 实现与范围

`ember_spark_paper_v1.tscn` 是可编辑的16根真实 Bone2D 和带权重的不透明 Polygon2D；运行仅依赖 NativeActorView 与外置 `ember_spark_motion_v1.tres`。风箱、阀门、炉体、烟囱、面罩、双腿膝足、双臂及短喷口的几何和六动作均新制；SporelingShapes 只复用拼片/描边工具，不复用菌盖造型。idle/walk/warning/attack/hit/death 仅有视觉属性轨道，没有伤害或方法事件。

实际 EmberSparkEnemy 继承 Enemy 的健康、移动/群体转向及生命周期；不是给旧 SPITTER 换色。新基础生命34、碰撞半径16、移动120、接触伤害15；射击保持200–290距离，仅330以内及镜头安全区启动。短头顶感叹号预警0.18秒，锁定当时目标位置后发射 -15/0/+15 度三枚火花，每枚速度280、伤害9、半径4、寿命1.1秒。不同于疾行者直线冲撞，也不同于原孢子射手的单发长寿命弹丸。这些是新原型参数，不覆盖原敌族数值，不签最终平衡。

喷口 Marker2D 真正位于右臂/Nozzle 骨链。肩臂±60度、喷口±35度限角；每次采样先恢复关节，避免隐身或同片段切换留下上次瞄准偏移。物理根不旋转，枪不绕身体公转。锁向射击/短后坐使用同一视觉时钟。出口必须在世界内、根到出口射线无阻挡且4px弹体形状不碰墙，否则安全回退物理中心；不是只检查零宽射线。

隐身、出生推动、死亡取消预警，不留重复射击或攻击姿态。健康和受伤血条均绘制，预警与弹丸使用统一敌对珊瑚色，不新增地面大圈或长蓄力。

RegionalEnemyFactory 是已实现角色的闭合映射：第一关根须/孢子，第二关疾行者/火花。未知关卡/角色返回 null，不偷偷用基础小怪充数。**第二关尚无实际章节导演、地图或菜单启动接入，不能据此开放第二关或声称完整关卡已制作。** 本轮未修改第一关导演，也没有新制大型/Boss攻击动画。

## RED、失败与修复

- 资源测试先失败：原创散射手资源不存在；新烘焙后102检查通过。
- 首次作者烘焙的循环字符串推断失败，补显式 String 类型后成功。生成的资源不依赖作者脚本。
- 首次集成测试目标夹具的 `hidden` 命名碰到原生信号，改为 `stealth_active` 并加入真实 player 组后，得到有效 RED：区域工厂不存在。实现工厂后通过，进一步扩展到42行为检查。
- 墙钟测试首次字典差值推断失败，补显式 float 后通过5检查。源工程独立记录预警0.183373秒；本轮实际隔离包预警0.183323秒。两者是实际 Actor 物理时钟，不是手动 advance 的动画长度。
