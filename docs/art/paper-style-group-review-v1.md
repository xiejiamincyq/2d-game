# 原创原生纸偶最小风格组 v1

2026-10-09；自主美术方向审查：**style-approved，仅风格方向，不是正式资源/游戏验收**。

采用“墨线纸偶式废土奇谭”：低饱和纸色、泥土/苔色、铜点缀，明确深墨轮廓；紧凑Q版正面剪纸造型，而非旧薄透明贴图或俯视3D。玩家、小怪、大型静态怪和局部受击效果先同屏审查，再扩展开始页与环境。

## 实际资源与审查

- 玩家“巡界员”：奶油色兜帽/护目镜、青绿色外套，区别于敌人的木石形体。十二个真实Bone2D、一个原生加权身体Polygon2D；小手枪为右手骨的WeaponGrip子节点，肩肘变换沿骨链带动，非根节点圆周公转。只制作正面静态皮肤；不冒充四朝向、握枪/射击/冲刺动作齐备。为避免强行让左手跨越不可达距离，本样板选择紧凑单手枪，正式各朝向另做手部姿态。
- 普通怪“树根追逐者”：沿用**本目标新作**的原创原生候选，非v13旧美术。木质面罩/叶冠、有机轮廓，与玩家和石板怪区分。六动作已在此前隔离候选中验证，尚未绑定实际Enemy时钟。
- 大型静态怪“岩根拦路者”：独立肩宽/头部/肢体rest与原创石板躯干、沉重根足；不是普通怪放大换色。十二骨、单张加权身体皮肤。**没有AnimationPlayer、预警或攻击库**，全角色骨骼齐备门仍未通过。
- 紧凑命中效果：新原创墨色短刺/象牙亮线/铜色中心，五个方向，设计0.14秒、最大半径14px。只控制视觉phase，不带伤害/碰撞/游戏计时。绘制动画不需把粒子效果伪装成人物骨骼。

GPU同屏图实际展示3倍细节与1倍游戏尺度，原生OpenGL/NVIDIA渲染，不是无头dummy图片。自主审查认为身份和材质区别成立，可进入正式小怪接入。局限：深墨在苔色暗地面上的外轮廓对比仍有限；正式地图要控制局部地面亮度、以实际密集战斗校验，不能仅凭静态明亮内色给全关卡可读性签字。大型攻击表现继续延期。

## 来源与契约

全部新形状由项目自行编写原生顶点/颜色，未临摹、描图或嵌入第三方位图。工程复用本目标已经验证的NativePaperSkin权重构建器和骨链方法，不等于复用旧角色美术。免费参考许可台账见[参考清单](campaign-free-reference-sources-v1.md)；本组未增加下载、付费资源、外部MCP或运行库。

本组记录位于`docs/art/style-manifests/paper_style_group_v1.json`，与实际可导出actor的native-manifests、旧PNG生产manifest分开。不得把技术作者脚本声明成正式可编辑场景，也不得伪造1024px位图源尺寸。角色正式资源需另行烘焙、原生目录校验和实际PCK载入。
