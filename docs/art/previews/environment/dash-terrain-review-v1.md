普通与隐身冲刺在已测薄墙、斜角、墙角、精确接触、浅重叠和边界条件下不再穿墙，保留穿敌及技能时序。**整个 S1 尚未通过**：非冲刺隐身走路在真实输入下仍能穿墙，作为下一独立缺陷处理。异常深嵌入只会拒绝冲刺并报警，不宣称已提供脱困。

## 红测与修复

1. 原实现 `global_position += velocity * step_time` 不经过地形查询。最小真实 Player/ArenaObstacle 红测：墙 `Rect2(80,-100,20,200)`，身体半径 16.9px，实际物理控制查询确实碰墙；旧冲刺终点 x=165，近侧上限 x=63.1，退出 1。
2. 首版扫掠补测再次失败：精确接触起点 x=63.1 朝内，终点 x=80.2875。零深度接触点对的差向量无法提供方向，而 cast_motion 忽略起点重叠。
3. 最终 TerrainSweep 仅对起点接触查询加 0.05px margin，以接触方向拒绝向内运动、允许向外/平行。含 margin 的深度超过 0.1001px 视为异常嵌入；正式扫掠恢复 margin=0。近面有最多约 0.05px 的保守截停容差。
4. 地形保留原层1，增加未占用位2；查询仅用位2，使用玩家实际 Shape2D 及世界变换。玩家隐身 layer=0/mask=0/shape.disabled 保留。先裁剪世界边界再扫掠，只应用安全比例；首次截停锁定本次剩余位移，不改变技能自然结束时间；暂停清理不解锁，下一次冲刺及出生/入场重置清除锁定。

API 依据：[Godot 4.7 PhysicsDirectSpaceState2D](https://docs.godotengine.org/en/4.7/classes/class_physicsdirectspacestate2d.html)。引擎文档不是实测替代。
