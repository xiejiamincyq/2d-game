# C 方案：加粗玩家轮廓接入

日期：2026-09-14。用户批准：选择 C，并要求轮廓更明显。保留原 B 角色/环境风格；不发布版本。

## 实施

- 玩家身体边缘增加浅奶油色粗线与深青衬边；在 84px 身体显示尺寸下，总轮廓带宽约 5px（纹理采样决定局部宽度），原预览约 2px。不填满剪影，不改变本体/敌人的透明度。
- 独立 Sprite2D 随玩家创建和销毁，共用同一身体图集。四方向、身体移动起伏与本体使用同一计算，不复制动画计时逻辑。
- 前方静态敌人图像的世界包围盒与玩家身体盒重叠时显示；这是保守矩形判定，不是像素精确遮挡检测，透明边角可能提前触发。
- 隐身、入场、死亡和不可见状态关闭；死亡信号立即隐藏，避免结束画面暂停后残留。
- 前景障碍盒覆盖玩家时不显示穿透轮廓，保留现有地形淡出逻辑。Boss 独立渲染器暂不作为触发来源。
- 本体保留原 y 排序；装饰性 CombatVfx z=20，轮廓 z=21，Projectiles 容器 z=22。真实弹体优先于定位提示。未更改伤害、碰撞、移动、攻击时机、地图生成或存档格式。

## 验证

新增回归测试先因组件缺失而失败，随后覆盖前/后/远处敌人、四向区域、移动跟随、隐藏敌人、隐身、入场、地形阻挡、原角色透明度、死亡即时隐藏及离场清理。

曾发现无窗口渲染路径对内建纹理采样器作为辅助函数参数报错；改为显式图集 uniform 后，无窗口测试及 Vulkan 实际渲染均无该错误。没有忽略错误或放宽测试门槛。

最终 Godot 资源导入和 37 个套件通过，当前运行输出 98,364 条断言。Python 74 项通过。四向固定姿态图 `player-outline-runtime-v1.png` 使用正式组件，原始游戏显示尺寸，已查看。

真实 AI 短测报告：`mint-farm-benchmark-outline-v1.json`；截图：`mint-farm-stress-outline-v1.png`。采集时组件确实可见，敌人数 61–79，1200 帧平均间隔 4.765ms、P95 8.895ms、最大 13.576ms。单机约 5.72 秒样本，不是长时间性能承诺，不用于宣称优化百分比。

## 尚未验收的边界

密集危险区域/弹体优先显示，仍可能覆盖部分轮廓；敌人原有血条和攻击预警没有重构，轮廓与预警交叉的可读性需要持续试玩。不能据此宣称所有密集战斗画面均已通过视觉验收。

本轮是“已批准 C 方案加粗并接入”，不是整体视觉问题清零。后续重点为危险区域填充和血条层级，以及完整局移动试玩。现有美术源资产未升级为 final。

## 复现

