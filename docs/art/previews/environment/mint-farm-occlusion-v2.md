# 玩家遮挡可读性 v2

2026-09-08，5分钟超载。遵循已选B美术风格，不生成或改变源图。

## 改动

- ArenaLayout只绑定当前玩家，逐帧检查最多13个障碍，不扫描敌人列表。
- 当玩家位于障碍排序点后方，且84×84玩家视觉包围盒与障碍可见区域重叠时，该障碍平滑降到32%不透明度；离开后恢复100%。变化速率5/秒，完整过渡约0.136秒。
- 判断使用障碍局部坐标，避免将局部障碍区域与全局玩家坐标混用。
- 同时淡化障碍贴图和实体底座，避免原来的底座继续挡住玩家。碰撞、地图生成、伤害和玩家本体透明度不变。
- 着色器保留CanvasItem调制色，使近不透明alpha归一化与父节点淡化能同时生效。

## 验证

- 新增绑定测试先失败，修复后通过。
- 测试覆盖平滑过渡、后方重叠、前方不淡化、侧面不淡化、远离不淡化、失去目标时恢复、玩家调制色不变；原有碰撞和比例断言保留。
- 36套Godot回归、98329断言通过（含既有测试，受随机地图数量影响）。
- 真正Main场景截图：mint-farm-runtime-v2.png。
- 四类障碍遮挡检查夹具：mint-farm-depth-v2.png；对比v1，后排玩家现在可见，前排玩家不受影响。夹具为每个障碍单独模拟一个后方玩家，不代表实际游戏同时存在四个玩家。
- Vulkan运行时渲染通过，人工检查未见透明背景白块或图集串色；git diff --check通过。
- 审查：没有创建逐帧材质、寻路缓存或额外纹理；只修改障碍调制色，不写玩家透明度。没有改变碰撞足迹、存档或随机数消耗。

## 限制与下一步

采用包围盒而非像素级遮挡判断，边缘处可能稍早触发淡化。源美术仍是draft，不是最终视觉验收。短花槽底座留白、地面重复感和密集战斗性能复测仍待处理。本批不发布Release。
