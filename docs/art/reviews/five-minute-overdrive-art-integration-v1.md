# 5分钟超载美术接入验收 v1

日期：2026-08-18

## 结论

有条件通过现有美术资源在 `5分钟超载` 分支的首轮接入。玩家 M2 资源和 Dasher A/B 已进入真实 `Main` 场景；分支原有玩法数值、碰撞和超载逻辑保持不变。

## 已验收

- 玩家使用 120 个偏航方向、每方向 3 度的 READY/MOVE/FIRE 图集。
- 玩家本体与武器在烘焙层中组合，运行时不再旋转独立屏幕空间枪支。
- 玩家绘制使用不透明合成帧；本轮实机截图未复现主体半透明故障。
- Dasher 使用 A/B 两个正式资源，运行时水平翻转并持续面朝玩家。
- Dasher 实例共享同一份编译 Shader，同时保留独立受击闪白参数，避免敌群生成时重复创建 Shader。
- Dasher 仍保留 `14` 碰撞半径、`6` 接触伤害和本分支 `258.5` 移动速度。
- 实机预览：`docs/art/previews/characters-combat/player-m2-runtime-combat-v1.png`。
