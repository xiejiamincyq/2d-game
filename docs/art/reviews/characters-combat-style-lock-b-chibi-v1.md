# 角色与战斗风格锁定：B 清爽玩具

- 决定日期：2026-09-03
- 用户选择：B「清爽玩具」
- 环境主题：C「废弃生化农场」
- 当前状态：`style-approved`

## 保留特征

- 纯 2D Q版，圆润玩具形体，中等干净描边，少量纹理。
- 深青、青绿、薄荷、暖奶油和珊瑚橙构成主体色板；酸绿只表达毒性或治疗。
- 玩家身体完全不透明，提供前、后、左、右四向读形。
- 枪械独立成层，但通过双手挂点固定，不绕玩家自由公转。
- 小怪使用单张右向母图并按玩家位置水平翻转；大型敌人强化体型差异。
- 固定斜俯视平面地图，温室、花槽、培养罐和管线形成遮挡与碰撞。

## 拒绝特征

- 俯视伪 3D 转台或 72/120 向水平旋转人物。
- 半透明人物、漂浮枪械、脱离手部的 360 度公转。
- 写实材质、重笔触废土绘本、粗重墨线或赛博霓虹堆叠。
- 复制现有游戏的角色、服装、武器、敌人、UI 或构图。

## 进入 gameplay-approved 前的检查

- 四向身体在 64×64 下轮廓与朝向可辨。
- 武器挂点在四向身体上稳定，射击时不穿过头部或脱手。
- 标准敌人与大型敌人在高密度战斗中可通过轮廓区分。
- 所有主体 Alpha 边缘干净，人物像素完全不透明。
- 替换美术不改变碰撞半径、伤害、移动或 AI。
