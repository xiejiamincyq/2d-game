## 已授权与可逆设计默认值

- 新美术与全部动画重新制作，不把旧整图摆动迁移到AnimationPlayer后称作新骨骼。旧资源仅作为迁移前的可运行回退，不作为新动画源。
- 自主采用“墨线纸偶式废土奇谭”：Q版清晰轮廓、分层哑光色块、铜绿/暖纸底色、区域专属强调色；无写实3D、无霓虹堆叠。固定当前2D视角，不回到3D转台；玩家武器附着手部，不绕身体旋转。
- 关卡解锁为永久进度；新档仅第1关开放，每次击败已开放关卡的Boss最多解锁紧邻下一关。重玩、死亡、重复死亡信号都不能跳关或撤销解锁；第6关完成不产生第7关。
- 设计默认：当前关卡失败重开局内构筑/地图，永久解锁不丢失；重玩已解锁关卡。此死亡策略尚未接入游戏，后续可调整；本阶段只实现直接要求的六关与顺序解锁基础。
- 局内地图种子、遭遇与风险奖励选择提供随机性；普通战斗→补给/奖励→可选高风险遭遇→本关Boss。先完成一关纵向闭环，再扩六关，不把原六波重命名冒充六关。
- 高血量大型敌人/Boss：先做拆件、骨骼、待机/移动/受击/死亡与技能挂点；所有角色骨骼资源完成之前，不制作它们的新攻击动画，现有攻击画面只作过渡。骨骼资源完成门与攻击动画完成门分别记录。

## 骨骼与画面验收

Godot 4.7原生Skeleton2D/Bone2D + AnimationPlayer；可使用分层Sprite2D刚性关节，必要时Polygon2D权重网格/替换手脸部件。所有角色使用真正肢体链和rest pose，支持取消/暂停/死亡时正确复位；动作不控制重复伤害，命中仍由战斗状态机唯一决定。

玩家需新四朝向身体、稳定握持与瞄准；普通敌怪需待机、行走、短预警、各自攻击、受击、死亡。大型敌人攻击动作按上述延后门制作。弹丸、危险提示、受击/死亡效果与菜单动效重新设计，不强求每一种粒子都是骨骼，但不沿用旧动画作为正式成品。

实际1280×720和小窗口检查透明边缘、身体不半透明、握枪、关节拼缝、脚底位移、危险可读性、血条/感叹号排布。密集画面检查AI与动画预算；测试、原生动态画面、真人手感分别验收，不将摆拍/模拟通关称为真人通过。

开始页要求新背景/主题、清楚的开始/继续/关卡选择/设置/退出、1至6关锁定状态与关卡简介、鼠标及键盘焦点可达、返回路径明显。支持1280×720、960×540、1920×1080；锁定关卡不能启动，损坏存档不导致无声覆盖或全部开放。
