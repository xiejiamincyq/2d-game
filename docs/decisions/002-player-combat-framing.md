# ADR-002：普通波玩家可操作取景

2026-10-04，取代ADR-001的无Boss不接管策略。完成情况以本片报告/原生记录为准；不是S3整体、人工签收或20地图验收。由工作区判断，不网页、不发布。

## 原因

当前09自然超载原图已显示玩家在地图上沿被顶HUD遮住。物理玩家半径16.9能走到世界边缘，原Camera2D的世界限位却使54px身体/武器包络进入UI甚至出屏。不能靠删除障碍、缩小可走区、传送玩家或盖在HUD上方解决。

## 决策

复用既有BossCameraFraming求解器，所有PLAYING使用实际可见战斗UI可用带与有限overscan。普通波保持1x目标，优先原玩家跟随/世界限位中心，仅在安全区必要时偏移。保留Camera2D原8.0内建平滑；若实际投影因滞后落出安全带，只纠正展示相机，不改玩家物理位置。Boss仍使用0.80—1.00联合取景和必要方向提示。

Enemy/Director/Boss仍只读独立玩家锚1x原世界限位参考，8.0参考跟随与暂停恢复同步；不读取展示position/zoom/overscan。普通波启用参考区与旧受击/限位镜头有机械空间合同差别，不能宣称轨迹、AI或生成完全零变化。测试同参考输入、仅改展示镜头的导航/刷怪距离隔离。

暂停冻结展示；恢复同步参考并清除普通波旧边缘偏移，防止将存档/初始化修正表现为玩家运动。非战斗、reset和退出恢复默认/解除引用。Boss消失但仍PLAYING时转为普通玩家保护，而非恢复边缘不安全的默认相机。

原生连续记录还证明：波次UI回调可在本帧pausable处理已跳过之后解除暂停，留下首个PLAYING帧无取景接管。Main仅负责在隐藏状态覆盖层后立即调用step_framing(0)，无需等下一帧；求解仍留在专属模块，不侵入伤害/移动/存档。

## 代价与验证范围

边缘必须适当显示世界外背景，不能承诺任何窗口下全身可见；极小安全区不足明确不保证。保持地图边界提示。需要验证四尺寸/八边缘、首绘制、震动、暂停/恢复/清场/结果、原MovementTest和Boss测试；记录自然全段包络与原失败，而不是把截图配额充作全程。许可证、性能、人类体验与20实际地图仍独立待验。

拒绝：只增加全局相机限位（不能解决HUD/平滑/首帧）；无限居中剩余区（露出过多世界外空白）；将普通波也关闭原Camera2D平滑（破坏恢复/8.0基线）；给导航消费者各设不同坐标补丁（重复反馈风险）。
