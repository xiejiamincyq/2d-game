# ADR-003：原生骨骼与独立六关进度

状态：Accepted（Godot骨骼/六关/新美术/大型攻击延后的范围来自2026-10-09人类指令；具体区域与死亡重开设计为可逆默认）。

## 决策

使用Godot原生Skeleton2D/Bone2D + AnimationPlayer和原创分层部件。保持即时射击操作，重做所有角色/动画；先完整骨骼资源再做高血量大型敌人攻击动画。不安装Spine或未审查MCP，当前文件与CLI足够进行原生制作。

引入独立ChapterCatalog、CampaignProgress与后续CampaignProgressStore；关卡ID是1..6，wave只属于关内遭遇。永久解锁不能从旧RunSnapshotStore.pending_stage推断；新保存路径不覆写旧run存档。未完成模块先不接入公开开始入口，第一关纵向切片通过后才切换。

## 取舍

原整图缩放不能满足真实转动肢体；直接复用旧素材违背重做要求。原生方案没有新运行库与付费授权负担；复杂骨骼编辑/网格仍需真实素材、关节校正与原生验证，不能承诺一键完成。

拒绝把旧六波包装为六关，拒绝将单个全局解锁数由波次推导。Boss本体/非攻击动作可先制作；过渡攻击保留并标未完成，不因首关需Boss就绕过人类指定延期门。

暗黑地牢仅作区域/风险奖励/长期选择的设计启发，不复制其资源和界面；新原创“墨线纸偶式废土奇谭”方向覆盖旧B清爽玩具，不改写旧资源的历史审批。
