# 敌方投射物初始化修复

本轮在检查旧敌方视觉语汇时发现实际碰撞错误，先停下调色，按测试驱动定位并修复。此片是技术行为修正，不伪称纯视觉等价，也不改变已批准的Q版风格。

## 根因和实际变化

`Projectile._ready`按`radius`生成`CircleShape2D`。狙击手和旧`Enemy.OVERSEER`分支先`add_child`触发ready，再赋半径，故声明3/5但物理圈仍默认4；调整为半径入树前赋值。狙击实际碰撞圈**4→3**，旧分支**4→5**，是与原声明保持一致，不称命中范围不变。最终首领使用独立`OverseerBoss`/`BossProjectilePattern`/`BossProjectile`，已在入树前配置半径，本轮不动它。

喷吐弹的配置半径5本已正确，但`global_position`在入树前赋值，带平移/旋转的父层下会将该值作为局部位置，生成位置偏移。现在其几何、伤害、速度等仍入树前配置，世界出生点移到入树后设置。当前identity父的世界位置不变，变换父的出生点得到修正。没有修改通用Projectile、引入动态radius setter、修改伤害/速度/数量、调色或最终Boss规则。
