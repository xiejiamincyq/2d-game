# v12 预览玩法说明

文件名沿用v10；本页说明已同步v12短预警预览。真人手感尚待确认。

纯2D Q版、每局随机障碍地图。六个普通波次清剿后进入最终Boss战；波次结算先免费领取一张卡，之后可用金币继续购买，关闭结算进入下一波。火力、机动、工程各有独立等级；每级对本系伤害乘1.05（从等级1起计算），与卡牌基础数值升级分别叠加。第四波以后、流派等级至少5且满足前置时出现对应终极进化候选；同局只能获得一种终极进化。

## 操作与敌人

WASD移动，鼠标瞄准，左键持续射击，右键向准心冲刺，Space暂停/继续。结算1–6选卡；开始页有有效存档时C继续；结果页R重开。准心内芯保持奶白，外描边为黑色，中心不变。暂停页可随时查看新招躲避提示。

敌人基础伤害为v9的三倍，包含近战、敌弹、投弹范围和Boss招式，不只是修改碰撞伤害。敌人生命和原有hitbox不变。追击者保留追击、普通近战和小怪群体绕行，新增两种攻击：

- 爪击：锁定72°扇区、64px伤害范围，头顶感叹号提示0.22秒，随后短促出手；侧移躲避，地形可挡伤害。不再绘制地面扇形。
- 扑击：头顶感叹号提示0.30秒并向锁定方向倾身，最多前进99px；只在实际可达距离发动，侧移躲避。撞到实体会停止，不能穿墙或追踪改向。不再绘制地面胶囊框。

新招每动作最多命中一次，使用追击者24点基础伤害，恢复缩短至0.20秒并恢复群体追击；独立冷却为爪击4.48秒、扑击4.50秒，用于补偿缩短的动作时间。普通贴身攻击前摇0.18秒、恢复0.20秒、冷却0.64秒。吐弹/狙击/投掷头顶提示分别0.18/0.30/0.35秒；冷却补偿维持原有周期。狙击最后0.10秒有细方向线，投掷仍保留落点圈和0.90秒飞行。重装怪与Boss前摇不变；青绿/薄荷色主要用于友方效果，小怪不把慢大怪当作速度领队。

## 三种终极进化

- 火力「榴弹协议」：射速为原20%，基础飞行速度为当前基础弹速48%，再加玩家实际移动矢量的30%；近敌爆炸造成主武器基础伤害的300%，仍受火力流派伤害倍率影响。静止基础弹速原248提升为297.6px/s，普通弹不改。
- 机动「顶级刺客」：冲刺距离和冷却各+20%，地刺基础伤害+28%、间距-30%（最低22）。冲刺后1.2秒隐身、穿敌但不穿地形，移速+30%，留下灼烧焰迹。没有修改地形碰撞规则。
- 工程「雷网矩阵」：全屏电弧伤害为原70%，触发间隔为同级普通电弧150%；无人机激光采用薄荷色、伤害+80%。例如等级1/基础1.85秒时普通电弧1.65秒、雷网2.475秒。

终极进化与连杀触发的短时无敌超载不同。连杀超载仍提供既有火力/移速/冲刺/地刺/激光强化，并使电弧频率×1.5；因此上述雷网例在连杀超载时为1.65秒。它不是再次获得一份永久进化，也不会在存档恢复时重复乘倍率。

本页描述当前源码与本轮v10候选，不改写v8/v9历史验收结果；普通EXE整局、人类手感、最低硬件和声音听感须分别验证。
