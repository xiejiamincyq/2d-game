# 玩家边缘取景与随机试玩复核

2026-10-04，分支 `5分钟超载`，Codex自行判断，无网页、不发布。自动试玩随机探索和停滞脱困已经在 `2e50c10` 实现，本片未再次修改驾驶策略，也未把手动玩家改为自动移动。这里只完成普通波可操作取景及当前驾驶的真实运行复核，S2—S5整体仍未完成。

## 修复及取舍

玩家物理半径16.9px允许走到世界边缘，但原限位镜头会使54px身体/武器包络被顶HUD遮住或出屏。复用BossCameraFraming保护所有PLAYING；普通波保持1x目标和原8.0内建平滑，仅必要时修正展示中心。暂停/恢复同步参考，非战斗恢复默认，Boss保留原联合构图/方向提示。实际换波回调在本帧处理已跳过后解除暂停，导致首绘制出屏：Main隐藏覆盖层后立即零时长求解，不推进战斗时钟。

不改Player物理位置、障碍/伤害/输入/存档参数。Enemy/Director/Boss使用独立玩家锚1x世界限位参考，不受展示平移/缩放反馈；普通波启用该参考有机械空间合同差别，不能称所有AI轨迹/生成零变化。详见[ADR-002](decisions/002-player-combat-framing.md)。边缘会露出有限世界外背景；极小不支持窗口、Boss极远分离、像素透明度及人工手感不在全身无遮挡承诺内。

## 保留的失败

自然v1/v2虽胜利且六景完整，各有一张首PLAYING帧完全出屏，面积11664px²、取景未启用；都不计可视性通过。旧Movement恢复回归促使普通波保留内建平滑，原生after-v3因发现首绘制漏洞被明确停止，30张无终报不计完成。fixture初态/非法转换/解析及隐藏玩家采样红测保留，不能假装全程一次成功。

第一次外部核算将1e-11浮点相消按严格正数计数而失败，v2披露同面积比对容差，未为此改生产。全量v1—v3终端结果存在，但Write-Host未进入Tee，预期日志不存在；明确重跑v4归档，不能用旧Boss门代替或重造日志。说明在包内`verification-notes.json`。
